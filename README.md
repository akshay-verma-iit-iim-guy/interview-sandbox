# Interview build (blank)

An empty, runnable Next.js app for starting a fresh build in each interview.

1. In GitHub, create a branch from `blank` named `round/<company>-<date>`.
2. In v0: Import from GitHub, pick this repo and that branch, link the Vercel project.
3. Build. Every push gets its own Vercel preview link to share.

Optional: set `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY` to store events from `track()`.
